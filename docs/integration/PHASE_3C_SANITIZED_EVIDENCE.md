# Phase 3C — Sanitized Run Evidence Contract

**Status:** Implementation candidate; owner review required.
**Scope:** deterministic in-memory sanitizer only. No persistence, artifact creation, transmission, or `evidence.ready` event.

## Allowlist

The sanitizer accepts exactly these values from an untrusted input object and constructs a new record:

| Field | Rule |
|---|---|
| `schemaVersion` | Constant `1.0`, generated by sanitizer |
| `runId` | 1–128 characters; ASCII letters, digits, dot, underscore, hyphen; cannot begin with punctuation |
| `status` | `passed`, `failed`, `timedOut`, `interrupted` only |
| `startedAt` | UTC ISO 8601 timestamp with millisecond precision |
| `finishedAt` | UTC ISO 8601 timestamp with millisecond precision; not earlier than start |
| `durationMs` | Integer from 0 through 604800000 |

All other input fields are dropped. The sanitizer never spreads, stringifies, logs, or persists the input object.

## Explicitly excluded

- Test title, test ID, project name, file path, URL, hostname, browser/device details.
- Error messages, stack traces, stdout/stderr, DOM, screenshots, video, traces, attachments.
- Cookies, authorization headers, credentials, tokens, environment variables, PII, account/customer identifiers.
- Arbitrary labels or user-controlled strings.

## Current boundary

This module is not connected to the Playwright reporter yet. It is a pure validation/sanitization utility with tests. No evidence artifact is created and no `evidence.ready` envelope is emitted. This avoids claiming evidence exists before storage, access control, integrity, retention, and cleanup are designed.

## Acceptance criteria

- Unknown fields never appear in output.
- Unsafe identifiers, statuses, timestamps, and durations are rejected with bounded static codes.
- Input data is not mutated.
- No filesystem, network, AI, MCP, or external package calls occur.
- Existing Playwright result and exit-code behavior remains unchanged.

## Deferred Phase 3C extension

A later owner-approved slice may add a local artifact writer only after defining: dedicated output root, path traversal and symlink defenses, restrictive permissions, maximum artifact size, atomic writes, checksum/provenance, retention, cleanup, and redaction tests. Only after a real artifact is created and access-controlled may `evidence.ready` be considered.
